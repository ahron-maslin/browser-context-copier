Welcome to Browser Context Copier

This extension reads the page you're currently viewing, cleans it up, and copies it to your clipboard as Markdown — ready to paste into an LLM chat.

Trigger it three ways:

  • Click the toolbar icon
  • Ctrl+Shift+C (Cmd+Shift+C on Mac)
  • Right-click the page and choose it from the context menu

It collects no data and makes no network requests of any kind — everything happens locally, in your browser.
